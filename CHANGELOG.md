# Changelog

## [1.0.5] - 2026-11-24

### Добавлено
- Экран «Почта (SMTP)» в настройках: сервер, порт, логин, пароль, отправитель,
  STARTTLS — ввод прямо на телефоне, пароль хранится шифрованным через
  Android Keystore (`data/MailSettingsStore.kt`, `ui/settings/MailSettingsScreen.kt`)
- Кнопка «Отправить тестовое письмо»
- Настройки из приложения имеют приоритет над `mail.properties`

## [1.0.4] - 2026-11-24

### Добавлено
- Реальная отправка письма с паролем при регистрации по SMTP (EHLO, STARTTLS,
  AUTH LOGIN) без сторонних библиотек — `data/Mailer.kt`, `data/WelcomeMail.kt`
- Настройки SMTP в `mail.properties` (не коммитится), значения попадают в
  `BuildConfig`: `MAIL_HOST`, `MAIL_PORT`, `MAIL_USER`, `MAIL_PASSWORD`,
  `MAIL_FROM`, `MAIL_STARTTLS`
- Кнопки «О программе» и «Поддержать» на главном экране
- Тесты `MailerTest` и `MailSenderTest` (последний проверяет порядок команд SMTP
  на локальном сервере-заглушке)

### Исправлено
- Регистрация не отменяется, если SMTP недоступен: аккаунт создаётся, а
  приложение сообщает, что письмо не отправлено
- Загрузка данных и Android Keystore при старте больше не выполняется на
  главном потоке

## [1.0.3] - 2026-11-24

### Добавлено
- Частота силовых тренировок: каждую неделю, раз в 2 недели и т. д. (пункт 1.3
  плана доработок) — экран «Расписание», поле `strength_every_weeks`
  в профиле и тест `PlanEngineTest`
- Резервная копия настроек сохраняет частоту силовых

### Исправлено
- `themes.xml`: атрибут `android:windowLightNavigationBar` перенесён в
  `values-v27`, так как он требует API 27 при minSdk 26 (ошибка lint `NewApi`)
- Схема БД расширена миграцией `onUpgrade` до версии 4

## [1.0.1] - 2026-11-21

### Добавлено
- Поддержка OAuth интеграции с часами (Amazfit, Garmin, Huawei, Polar)
- Признак "гонка" для тренировок из intervals.icu
- Функция тейпера для подготовки к соревнованиям
- Синхронизация вручную или раз в день

### Изменено
- Обновлена версия приложения до 1.0.1
- Улучшена структура проекта
- Добавлены необходимые зависимости для OAuth

### Исправлено
- Оптимизирована работа с OAuth токенами
- Улучшена обработка ошибок при подключении к часам

## [1.0.0] - 2026-11-01

### Добавлено
- Базовая версия приложения StartLine
- Основные функции трекинга и записи тренировок
